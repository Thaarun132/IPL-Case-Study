Team Aggregation Analysis

Mumbai Indians Led All Franchises in Aggregate Offensive Output in 2019

Executing a grouped sum aggregation to calculate total runs scored across all batters per team.

-- Query 8: Maximum Runs Scored by Team in 2019

SELECT 
  Team, 
  SUM(Runs) AS TotalTeamRuns 
FROM `IPL_db.Batsmen2019` 
GROUP BY Team 
ORDER BY TotalTeamRuns DESC 
LIMIT 1;

BigQuery Query Result Executed in 0.22s

Row Team TotalTeamRuns
1 Mumbai Indians (MI) 2,430

Insight Summary:

MI's balanced middle order yielded the highest cumulative run output, paving their path to the 2019 IPL title.

Batting Efficiency Spotlight

High Volume Plus Elite Speed: Kane Williamson Dominated IPL 2018

Filtering top run scorers maintaining an aggressive average strike rate threshold (SR >= 130).

-- Query 2: Most Runs in 2018 with SR >= 130

SELECT 
  Player, 
  Runs, 
  SR 
FROM `IPL_db.Batsman2018` 
WHERE SR >= 130 
ORDER BY Runs DESC 
LIMIT 1;

Multi-Season Continuity

Cross-Season Relational JOINs Reveal Multi-Year Batting Stalwarts

Joining 2018 and 2019 seasonal tables via INNER JOIN on Player keys.

-- Query 4: Most Combined Runs (2018 + 2019)

SELECT 
  bat2018.Player, 
  (bat2018.Runs + bat2019.Runs) AS TotalRuns 
FROM `IPL_db.Batsman2018` AS bat2018 
INNER JOIN `IPL_db.Batsmen2019` AS bat2019 
  ON bat2018.Player = bat2019.Player 
ORDER BY TotalRuns DESC 
LIMIT 2;

Calculated Fields & Filtering

Derived Fields Highlight Extreme Boundary Impact & Special Hauls

Creating aliased boundary sum calculations (Fours + Sixs) and low-over filters.

-- Query 5: Max Boundaries (Fours + Sixs) in 2018

SELECT 
  Player, 
  (Fours + Sixs) AS TotalBoundaries 
FROM `IPL_db.Batsman2018`
